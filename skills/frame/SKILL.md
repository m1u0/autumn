# Frame

Settle the decisions that meaningfully shape the outcome before starting.

- **Ground first.** Look up discoverable facts yourself (offload bulky lookups to a fresh read-only subagent) and run cheap, reversible checks instead of asking what you can find out directly.
- **Challenge weak framing.** If a sharper premise or angle would make the work deeper rather than bigger, surface it before locking in the plan.
- **Ask upstream decisions first.** Use your judgment on which irreversible, taste-defining, or path-changing decisions belong to the user—settle upstream forks before asking follow-up questions that depend on them.
- **Recommend a default for each question** so the user can accept with a quick "yes" or override where it matters, then start executing once the key decisions are settled.
